A desktop-based Clinic Management System developed using C# Windows Forms and SQL Server. The system is designed to manage daily clinic operations including patients, doctors, staff, treatments, tokens, medicines, products, stock, billing, payments, and company records.

 **Project Overview**

The Clinic Management System provides a centralized desktop application for managing important clinic records and daily activities.

It helps organize patient information, doctor records, treatments, medicines, product inventory, billing and payment information in a structured database system.

 **Main Features**

**Patient Management**

  * Add and manage patient records
  * Update patient information

 **Doctor Management**

  * Manage doctor records
  * Update doctor information

**Staff Management**

  * Add and manage staff records
  * Update staff information

**Token Management**

  * Manage patient tokens
  * Update token records

**Treatment Management**

  * Add and manage treatment records
  * Update treatment information

**Medicine Management**

  * Manage medicine records
  * Update medicine information

**Product Management**

  * Add and manage products
  * Update product information

**Stock Management**

  * Manage available stock
  * Update stock records

**Company Management**

  * Manage company information
  * Update company records

**Billing Management**

  * Create and manage bills
  * Update bill records

**Payment Management**

  * Manage payment records
  * Update payment information

**Dashboard**

  * Provides a central interface for accessing different modules

##  Database Setup

This project uses **Microsoft SQL Server** for storing and managing clinic data.

 **Steps**

1. Open **SQL Server Management Studio (SSMS)**.
2. Create a new database for the Clinic Management System.
3. Create/import the required tables.
4. Open the project in **Visual Studio**.
5. Update the SQL Server connection string in the project according to your SQL Server instance.
6. Build and run the application.

   ##  How to Run

1. Clone or download this repository.
2. Open the project in **Visual Studio**.
3. Make sure **SQL Server** is installed and running.
4. Create and configure the project database in **SQL Server Management Studio (SSMS)**.
5. Update the database connection string according to your SQL Server instance.
6. Restore or build the project in Visual Studio.
7. Press **Start** or **F5** to run the Clinic Management System.
